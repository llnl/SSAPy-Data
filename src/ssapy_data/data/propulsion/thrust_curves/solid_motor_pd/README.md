# Public-Domain Solid Motor Thrust Curves

Use this directory for normalized CSV copies of public-domain time-thrust data.

Recommended source:
- ThrustCurve.org API records where `license` is exactly `PD`.

Suggested normalized CSV columns:
- `time_s`
- `thrust_n`

Retain per-file provenance in a neighboring metadata JSON file or in `../../sources.json`.
