# Electric Propulsion Throttle Maps

This directory contains small, redistributable benchmark throttle maps for satellite electric propulsion models.

Files:
- `next_tt10_thrust_comparison.csv`: NASA Evolutionary Xenon Thruster (NEXT) 40-level throttle-table thrust comparison from NTRS 20100042402.
- `hermes_tdu3_throttle_map.csv`: HERMeS TDU-3 Hall-thruster reference and expanded firing-condition thrust data from NTRS 20210023838.
- `aeps_etu2_throttle_map.csv`: AEPS ETU-2 Hall-thruster reference and PPE firing-condition thrust, specific impulse, and efficiency data from NTRS 20210015721.
- `spt140_performance_map.csv`: SPT-140 Hall-thruster experimental operating points from NTRS 19980016322.
