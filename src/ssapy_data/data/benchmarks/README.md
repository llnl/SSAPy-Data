# SSATK propagation benchmark data

The `long_term/` directory contains Cartesian state histories generated by the
SSATK benchmark demos against GMAT R2026a and Orekit 10.3.1. All cases use an
Earth-centered degree/order-0 point-mass model with the same initial radius,
velocity, duration, and output cadence in each propagator:

| Case | Radius | Duration | Cadence |
| --- | ---: | ---: | ---: |
| LEO | 7,000 km | 7 days | 300 s |
| GEO | 42,164.169 km | 30 days | 900 s |
| Cislunar radius | 384,400 km | 30 days | 1,800 s |

The cislunar case is an Earth-centered two-body regional comparison. It does
not model the Earth-Moon-Sun system or claim lunar-transfer fidelity.

CSV columns are `elapsed_seconds, x, y, z, vx, vy, vz`; GMAT values use km and
km/s, while Orekit values use m and m/s, matching the native report units of
each benchmark runner.
